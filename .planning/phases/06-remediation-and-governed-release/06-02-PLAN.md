## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `PHASE_TABLE` to `run.drive()` | the table is the sole authority on which phases an audit run executes; a wrong entry changes what a security audit does. |
| `DETERMINISTIC_ACTIONS` to the filesystem | a registered action writes into the workspace on the driver's behalf. |
| Workspace artifacts to `artifact_gate` | the gate's verdict depends on artifacts an earlier phase must have produced. |
