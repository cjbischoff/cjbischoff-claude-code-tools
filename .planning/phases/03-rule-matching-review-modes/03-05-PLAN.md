## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| review-filter subagent response → `reflection.validate_verdict` | An untrusted model response asks for findings to be removed. |
| rendered prompt → subagent | Diff text and finding text, both potentially attacker-influenced, enter a model prompt. |
| surviving findings → `findings_gate` | Findings cross into disposition assignment. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Elevation of Privilege | `reflection.apply_verdict` | high | mitigate | Retract-only by parsing: only the id list and analysis text are read, ids outside the submitted set raise, and `PROTECTED_SUBJECT_CLASSES` is checked in code so a model can never remove a memory-safety, concurrency, linkage, compatibility, or unused-parameter finding (D-16). |
| T-03-15 | Elevation of Privilege | `findings_gate` disposition ladder | high | mitigate | The ladder assigns only non-shipping review dispositions; `confirms_alone` remains the sole path to `confirmed` or `fixed`, and an unknown class raises rather than defaulting into a weaker disposition (REV-03). |
| T-03-16 | Tampering | prompt injection via diff or finding text | high | mitigate | The prompt's ordered method puts the protected-subject veto at step 1 above both removal grounds, and the code veto backstops it, so injected text steering the model toward a removal still cannot remove a protected finding. Only two tool shapes are accepted; any other response raises. |
| T-03-05 | Repudiation | reflection ledger | medium | mitigate | Applied retractions, refused retractions, and fail-open skips each get their own ledger entry with path, reason, and analysis text, and both zero cases render explicitly, so a never-ran filter is distinguishable from a retracted-nothing filter (D-14, D-15). |
| T-03-08 | Denial of Service | per-file reflection loop | medium | mitigate | Each file's filter call is isolated by a handler that records a skip and continues; a raised exception, a timeout, or a malformed response cannot abort the run or discard another file's results. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed; `dependencies = []` holds under REL-03 and RESEARCH.md's Package Legitimacy Audit records zero proposed packages. |
