```python
@classmethod
def for_target(cls, target: str, *, base: Path | None = None, runner: RunnerT = subprocess.run) -> "RepoMemory":
    """Resolve (do not create) the sidecar RepoMemory for a target repo."""
    b = base or memory_root(target)
    return cls(root=b / repo_slug(target, runner=runner))

# repo_memory.py:132-135
@property
def workspace(self) -> Workspace:
    """Return the Workspace rooted at this memory's sidecar directory."""
    return Workspace(self.root)
```

**Docstring fix (same commit, per RESEARCH.md Open Question 2):** `run_review`'s current
docstring line `root: Target repo root; the workspace and its artifacts/ dir live here.` is
inaccurate post-fix — update to state artifacts live under the resolved `.sec-overlay/<slug>/`
sidecar, not `root` directly.
