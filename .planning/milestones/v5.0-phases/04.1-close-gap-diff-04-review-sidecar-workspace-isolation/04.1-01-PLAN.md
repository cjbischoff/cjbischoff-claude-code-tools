<objective>
Close the DIFF-04 milestone-audit blocker: make `run_review` resolve its workspace through
`RepoMemory.for_target(root)` -> `<root>/.sec-overlay/<slug>/`, the same sidecar convention
`scan` (cli.py:407-411) and `audit` (cli.py:440-445) already use, replacing the direct
`Workspace(args.root)` construction at cli.py:172-174. Pin the convention with a regression
test, and rewrite every existing test assertion that currently encodes the bug as correct.

Purpose: today every review artifact — coverage manifest, `runs/review_prompts/`,
`runs/review_plan.json`, `report.md`, `review_ledger.json` — is written into the reviewed
repo's tracked working tree. That pollutes the repo under review, and it means REV-03's
receipt ledger is not a durable non-tracked artifact. The milestone audit rates this a
BLOCKER affecting DIFF-04, REV-03, and indirectly VAL-03.

Output: a three-line production fix, a corrected docstring, one new regression test, ~28
rewritten assertions across four test files, four doc updates, a CHANGELOG entry, and a
patch version bump — all in one commit, because the doc-tracks-code hook requires the
folder READMEs alongside the code and because splitting the production fix from the test
rewrites would leave an intermediate commit with a red suite.
</objective>
