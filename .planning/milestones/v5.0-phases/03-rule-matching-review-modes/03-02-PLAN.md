## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `--rule` CLI argument → filesystem | An operator-supplied path is opened for reading. |
| project/global `rule.json` → filesystem | Repo-controlled and home-directory-controlled config names arbitrary rule-file paths. |
| rule-file text → reviewing agent prompt | Rule text is injected into an LLM prompt as its instruction block. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | `read_rule_file_safe` | high | mitigate | Resolve symlinks first, then require the resolved path under the resolved repo root via `is_relative_to`, then restrict the resolved suffix to `.md`/`.txt`/`.markdown`. A checked-in `rule.json` pointing at `~/.ssh/id_rsa` or `../../etc/passwd` is rejected. |
