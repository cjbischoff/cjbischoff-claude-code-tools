## Interface contract (read before touching either file)

| Symbol | Signature / shape | Constraint that bites here |
|--------|-------------------|----------------------------|
| `review_findings.apply_profile` | `(list[GatedFinding], str) -> tuple[list[ReviewFinding], list[DroppedFinding]]` | Returns wrappers, not `Finding`s |
| `review_findings.ReviewFinding` | fields `finding`, `defect_class`, `disposition`, `profile` | `.finding` is the inner `Finding` |
| `review_findings.classify` | `(Finding) -> str | None` | `None` when the class is outside `GENERAL_DEFECT_CLASSES` |
| `findings_gate.disposition_without_receipt` | `(str) -> str` | **Raises ValueError on an unknown class** — never call it with `None` |
| `findings_gate` module | imports `GENERAL_DEFECT_CLASSES`, `UNCONFIRMED_DISPOSITION`, `NEEDS_DEPLOYMENT_TESTING_DISPOSITION` from `review_findings` at module level | A module-level reverse import is a cycle |

| `Finding` | `.id`, `.file`, `.line`, `.rule_id`, `.cls` | Path attribute is `.file`, not `.path` |
