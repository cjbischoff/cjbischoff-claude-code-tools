`rule_glob.py` — port the matching semantics from OCR `system_rules.go` under D-02.
`expand_braces(pattern)` finds the first `{`, then the first `}` after it, splits the interior on `,`, and returns `prefix + option + suffix` for each option; a pattern with no `{` or no closing `}` returns a one-element list holding the input unchanged. Expansion is deliberately non-recursive and handles only the first brace group, matching OCR — do not "improve" it into a recursive cross-product.
`glob_match(pattern, path)` lower-cases both arguments per D-04, then performs a `**`-aware segment match. Split both on `/`; a literal `**` segment consumes zero or more path segments; every other segment is matched with `fnmatch.fnmatchcase` against exactly one path segment. Implement it as a small explicit segment walk. Do not call the 3.13-only whole-path matcher on `pathlib.PurePath` and do not raise the `requires-python` floor: D-01 keeps the floor at 3.12 and ships this matcher instead.
`BUILTIN_PATH_RULE_MAP` is a module-level `dict[str, str]` whose insertion order is the match order — Python preserves it, so no custom JSON decoder is needed (OCR needs one only because Go maps are unordered). Seed it with `"**/*.py": "python.md"` for this slice; later plans extend it. `BUILTIN_DEFAULT_RULE` is `"default.md"`.
`resolve_rule_doc(path)` iterates `BUILTIN_PATH_RULE_MAP` in order, expands each pattern's braces, and returns the read text of the first doc whose expanded pattern matches; on no match it returns the text of `BUILTIN_DEFAULT_RULE`. `builtin_rule_docs_dir()` derives the docs directory from `Path(__file__)` so resolution works regardless of the process working directory — the same hazard `test_preflight.py`'s vendored-rules test guards. Only the built-in layer exists in this slice; plan 03-02 adds the other three layers and the safety gate.

`rules/rule_docs/python.md` and `rules/rule_docs/default.md` — port OCR's checklist form per D-05: `####` section headings with terse imperative bullets, and an explicit "Do not report in the following cases:" block per section. These are LLM prompt payloads — do not apply an STE100 prose pass and do not rewrite them into human documentation.

`reflection.py` — `ReflectionComment` carries only `id`, `content`, and `existing_code`; `build_payload` deliberately omits severity, category, and suggestion so the filter cannot rank or rewrite, only remove. `apply_verdict(findings, verdict, *, path)` accepts the verdict as an already-parsed mapping (no CLI call, no API call, no subprocess — D-13 keeps dispatch in SKILL.md) and returns `(kept, retractions)`. It removes a finding only when its id was in the submitted payload AND the verdict names it AND its `cls` is absent from `PROTECTED_SUBJECT_CLASSES`. `PROTECTED_SUBJECT_CLASSES` is a `frozenset` covering memory safety, concurrency, linkage/declaration consistency, behavioral or compatibility change, and unused-parameter subjects — the D-16 veto lives in code, not only in the prompt. Follow `evidence.confirms_alone`'s shape: the module decides, the model only proposes. Copy rather than mutate the input list, mirroring `phase_gate._with_position`. Sort retractions by `(path, line, rule_id)` so the ledger and the report cannot disagree.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo file tree → `rule_glob` | Rule-doc paths and file paths from the diff cross into filesystem reads. |
| rule-doc text → reviewing agent prompt | Rule-doc content is injected into an LLM prompt as instructions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | `rule_glob.builtin_rule_docs_dir` | medium | mitigate | Resolve the docs directory from `Path(__file__)`, never from the process working directory or an environment variable, so a hostile cwd cannot redirect the read. |
| T-03-04 | Elevation of Privilege | `reflection.apply_verdict` | high | mitigate | Retract-only by construction; an id outside the submitted payload is ignored; `PROTECTED_SUBJECT_CLASSES` is checked in code so a model response can never remove a memory-safety, concurrency, linkage, compatibility, or unused-parameter finding (D-16). |
| T-03-05 | Repudiation | `report.write_review_ledger` | medium | mitigate | Every retraction and every fail-open skip writes a ledger entry, and the zero case renders an explicit sentence, so a silently-never-ran filter is distinguishable from one that retracted nothing (D-14, D-15). |
| T-03-08 | Denial of Service | `reflection` per-file loop | low | mitigate | A per-file `try`/`except` records a skip and continues; one bad file cannot abort the run. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this phase; `helpers/pyproject.toml` keeps `dependencies = []` under REL-03, and RESEARCH.md's Package Legitimacy Audit records zero proposed packages. |
