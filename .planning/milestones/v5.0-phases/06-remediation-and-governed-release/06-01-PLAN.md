## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv to `run_review` | `--root` and `--workspace` are operator-supplied filesystem paths; both cross into path resolution and subprocess `cwd`. |
| `run_review` to git subprocess | `root` becomes the `cwd` of a real `subprocess.run` call. |
| Workspace path to filesystem writes | the resolved workspace is where the run writes its manifest, ledger, and prompts. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01-01 | Denial of Service | `run_review` root handling | low | mitigate | Task 1's guard turns an unhandled `FileNotFoundError` into a clean exit 2, so a bad path cannot crash the process mid-run or leave a half-written workspace. |
| T-06-01-02 | Tampering | `--workspace` path resolution | medium | mitigate | Resolve only through the existing `load_paths(workspace=...)`, which already applies the repo's path handling; add no second resolver and no direct `Path` join on operator input. |
