## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv -> `diffscope` | `--base` and `--head` are operator-supplied strings that reach a `git` argv. |
| `git` stdout -> parsers | Path and status text produced by git is parsed into records and glob-matched. |
| Repo working tree -> `positioning` | File content read to confirm a claimed finding location. |
| Run artifact dir -> Phase 4 | The manifest becomes an input to a later phase's resume path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `diffscope.validate_ref` | high | mitigate | Allowlist pattern `^[A-Za-z0-9._/-]+$` rejects a leading dash, so no ref can reach git as an option; `ValueError` is raised before any subprocess starts. The existing `--` separator stays. |
| T-02-02 | Tampering | `diffscope.resolve_ref_sha` | medium | mitigate | Resolve both refs to SHAs once at run start (D-07); every later git call in the tracer path receives a pinned SHA, closing the TOCTOU window where a ref could be repointed mid-run. |
