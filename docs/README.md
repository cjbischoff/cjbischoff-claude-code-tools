# docs/

Design specs, planning documents, and architecture decisions for this marketplace.

**Naming convention:** specs live under `docs/superpowers/specs/` as
`YYYY-MM-DD-<topic>-design.md`. Decisions live under `docs/decisions/` as
`YYYY-MM-DD-<topic>.md`; that folder carries its own README and index.

**Writers:** Claude Code sessions in this workspace, on a branch, with user review
before merge.
